# Repository instructions

## Documentation language

Write all new and updated documentation in English, including Markdown files,
research notes, experiment plans, and explanatory report text.

Preserve benchmark prompts, captured model responses, quoted token strings,
identifiers, and other source evidence verbatim.

## Delivery scope

Keep base-model pruning, weight modification, training, recovery experiments,
and their generated artifacts outside this runtime optimization branch.
Runtime changes, inference tests, and reproducible inference measurements belong
here. Model weights remain external and must never be committed.
